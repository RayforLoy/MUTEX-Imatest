# 使用指南

## 语言、显示与菜单（v0.9.0）

程序默认跟随系统语言：中文系统使用简体中文，其它系统使用 English。右上角选择器与「显示 → 语言」同步，可以即时切换并保存。用户文件名、模板名、通道代号、单位和测量数据保留原样。

「显示 → 主题」提供跟随系统、浅色和深色；主题覆盖主窗口、菜单、禁用项目、对话框、表格和曲线背景。显示菜单还可开关热力图、测点数值、两侧面板，恢复窗口布局，查看日志，以及使用原有 90° 旋转、镜像、适合窗口和 100% 预览。显示变更不重新分析，也不修改源文件。

「编辑」提供当前测点结果、测量表 TSV 和文件路径复制，图像全选、从队列移除及分析项目选择。移除只影响当前队列，不删除磁盘文件；任务运行时禁用移除，避免后台结果对应到错误的行。

「设置」可展开专业分析参数，调整资源 / 解码、评价目标，导入或导出分析配置，打开设置目录，以及恢复默认分析参数。恢复分析默认值时保留本机缓存目录和资源预算；已生成的结果不改写。界面语言 / 主题保存在独立显示偏好中，不混入测量配置。

## 质量原因与锐化提示（v0.9.0）

灰色测点的悬停提示、测量表和详情会列出具体原因，可同时显示多个限制，包括剪切、取样不足、图像未覆盖、条纹不符、拟合失败、低频参考不足和物理标定缺失。CTF 未跨阈值与数据有效性失败分别说明；缺失数值不当作零。

成功的新分析检出有效光晕或 SFR 峰值增益后，软件提示「检测到锐化，测量结果可能不可靠」，并列出证据和受影响文件。批量分析完成后合并提示，弹窗不会阻塞工作队列；打开旧结果或切换通道不会重复提示。锐化 / 振铃迹象不能证明具体处理历史，未检出也不证明未经锐化。

若 USAF 白缝中的细小纤维产生额外暗谷，只有真实三条线的周期、位置和线宽均能核实时，程序才排除窄且浅的杂质候选，保留污染警告与原始剖面；不会用邻居数值平滑或补齐测量。强遮挡和图案不符继续排除。参见 [USAF CTF](USAF_CTF.md)。

## 结果评价与参考

当前画面的彩色评价标签打开「评价与参考」页；「测量明细」有逐点评价，「所选分析结果」增加中位数、最差值和参考标准。左侧每个项目（含不可用项）的悬停提示都有参考值、适用条件与建议。绿色的工程参考只表示符合 MUTEX 建议；验收通过仅针对明确设置的用户目标，无效或受限结果不能被平均值掩盖。

在「图像质量 → 评价参考与自定义目标」设置上下限、允许区间、目标单位及说明，也可关闭默认工程分档、导出或导入目标。应用后更新当前结果与后续分析，不重算像素。切换预览单位不改变目标；物理单位缺少标定时不判通过。旧结果可直接重评，报告重新导出即可。HTML/PDF 均包含评价，启用数据附件时另存 `evaluation-results.json` 和逐点 CSV。

详见 [全部 65 项参考定义](MEASUREMENT_EVALUATION.md) 与 [13 类工作台评价](WORKFLOW_EVALUATION.md)。

## 第一次使用

1. 双击完整解压目录中的 MUTEX Imatest.exe，或运行项目根目录的 启动 MUTEX Imatest.cmd。
2. 点击「合成示例」。软件生成并分析 9 张 48 位 TIFF；该示例有已知模糊与色通道位移，不是设备评测。
3. 选择图像，点击白色测量点查看 SFR / ESF / LSF 或星图/USAF 响应。图案种类在测量明细中标注。
4. 点击「焦位 / 垫高序列」，检查每张的 mm 高度，开始拟合。最佳焦位地图及场曲信息位于对应标签页。
5. 专业模式提供 RGB、曲线、窗口函数、配准、资源和解码设置。简易模式保留核心流程与必要的输入曲线选择。

## 模板预览、管理与加密导出（v0.5.0）

顶部「图卡模板 ▾」和菜单栏「图卡模板」提供模板管理、新建 / 导入 SVG/PDF、编辑当前模板、导入模板包和导出当前模板。右侧模板选择列表显示缩略图，选中后在下方显示较大的预览、图案数量和标定状态。

「模板管理」可搜索、预览、使用、编辑、复制、改名、归档和导入 / 导出。公开内置模板保持只读；编辑时建立用户副本。归档只移动用户定义到本地图卡库 backups 子目录，保留原图及参考文件；需要恢复时可从备份目录导入定义。相同测量定义的重复导入会复用已有模板。

选择「导出当前模板（加密）」后填写文件名，再设置至少 8 位口令并确认。文件后缀为 `.mxtpl`，采用 ZIP 快速压缩，包内只有格式说明和加密二进制；测量定义、缩略图及供配准使用的栅格参考均被加密，不包含原始 SVG/PDF 矢量文件。导入时需要同一口令。软件不保存口令，请自行保管并通过合适的渠道提供给接收方。已存在的同名模板包不会被覆盖。

导入后的模板可使用栅格参考做配准、按已有 ROI 分析；需要重新从矢量图展开 USAF 等编辑时，应在自己的电脑上重新关联源文件。原始矢量文件不会随包分发；获得口令并导入的接收方可以访问派生的栅格与测量数据。

新增「通用棋盘格」：10×8 方格，9×7 内角点，名义格宽 16 mm，A4 横版。请按 100% 打印并核实实物尺寸后再标定。完整棋盘格可检查角点定位及投影配准残差 RMS；该残差同时受靶材、平面度、拍摄和镜头影响，单张结果不直接作为镜头畸变系数。需要拍全 ROI，裁掉棋盘格本体时该模板会报告越界。

## 你的图卡与扫描/翻拍文件

先在「编辑 / 导入图卡模板」导入 SVG 或 PDF。PDF 可指定页码；程序只存储本地原文件路径，生成缩略图，不自动上传或公开你的源文件。

在缩略图上拖出每个 ROI，在弹窗选择斜边、USAF、星图等图案，并填写参数。图卡实际宽高必须与制作后的实物一致；勾选「实际尺寸已校准」后才启用物方 lp/mm。名义扫描 DPI 仅作为元数据，不能替代图卡标定。平铺布局可先生成规则斜边网格，再调整；自动斜边检测也只生成候选，必须检查是否框入文字、边框或多条线。

CorelDRAW 等软件的标准 SVG 1.1 DOCTYPE 会在内存中移除后再渲染，不访问 DTD 地址，不改写原始 SVG；脚本、实体、外部文件和外部样式仍受限制。SVG 的显式物理宽高会读入尺寸栏，仍需按实物确认「实际尺寸已校准」。

对于重复 USAF 矢量图卡，可用「从 SVG 识别单频 USAF」选择组、元素及竖线/横线/双向。例如组 3 元素 5 为 12.699 lp/mm；软件从黑色矩形或四顶点多边形条纹生成 ROI。当前识别要求 SVG 已展开 transform；不满足时可手工框选。保存后自动选择「USAF 矢量配准」和适用指标。分析使用低频条纹与标尺/文字定位，再逐单元在原像素拟合；定位未通过的单元明确显示无效，不测量。当前自动定位用于 2-8 列、至少 6 个重复单元的排列。

v0.2.0 的「整卡多频率 / RGB」会一次展开全部 USAF 频率、横竖双向与 R/G/B/Y/Y_align 五通道，提供 CTF 曲线、已确认分辨率、二维通道位移、方向差异、DPI / lp/mm / LW/PH / LP/PH 换算和原尺寸灰度 TIFF 导出。[完整步骤与定义](WHOLE_CARD.md)。

图像上方的「USAF 双向 / 竖线 / 横线」可分别观察方向差异。竖线衡量图像横向细节，横线衡量纵向细节。导出报告跟随当前方向选择，保存会话保留完整原始测量。CTF 无量纲，不直接转换为 MTF；未知的锐化、剪切及输入曲线仍影响结果。

选择或重新打开单频 USAF 模板时，软件自动使用「固定频率对比度（USAF / 星图）」；MTF50 和 CTF50 不适用于单个 USAF 三条纹元素，会在列表中禁用。多频率模板可用 CTF50/20/10。软件记住所选模板及指标，打开已有分析记录时恢复该记录的模板和测量参数。

分析项目列表和通道下拉框以白底深青色显示可用项，灰底灰字并附“不可用”显示不支持项；鼠标悬停可看原因。整卡模板的“RGB 位移 R−G / B−G（二维幅值）”自动切换对应颜色通道；通道框暂时固定，选择另一通道对请切换指标。无需为单频 / 双向 / 整卡另存多个同名模板：同源同尺寸的生成版本会自动合并，保留手工 ROI 和标定，原模板备份在图卡库 backups 目录。

简易模式也提供「剪切处理」。严格模式会将超过剪切比例门限的测点判为无效，因此可能只有部分区域显示热力图。若用于相对调焦，可选择「相对调焦：保留数值及剪切提示」后重新分析，或点击提示下方的「按相对调焦重新分析」。这会保留已算出的对比度和剪切警告，定位失败的区域仍无效；不会恢复被剪切丢失的信息。界面分别列出参与热力图、被剪切排除、保留剪切提示和定位失败的数量。输入曲线保持用户选择；未知曲线下为输入信号响应。

保存到图卡库，再导入实际照片或扫描文件。如果图卡在画面中有留白或裁切，依次点击左上、右上、右下、左下四角做配准，然后重新分析。特征配准属于候选定位，重复 USAF/星图可能错配，需要看叠加 ROI 验证。

扫描仪输出选择 RGB 48-bit TIFF，关闭锐化、自动对比度、降噪、色差矫正等会影响测量的处理。对于 TIFF 的「线性」不能仅凭 16-bit 推断：按扫描软件输出曲线选择线性、sRGB、Gamma 或 OECF。不知道时选未知，软件会明确标注输入信号响应。

RAW 使用线性相机 RGB，白平衡、sRGB/ICC 转换不进入测量，保留原始 CFA。读取与测量使用原生坐标，没有自动 EXIF 转向。大图用滚轮缩放、拖动平移、100% 查看原像素显示。显示取样不参与分析。

右下角的「预览缩放：…%」表示图像在预览窗口中的显示倍率；100% 为一个源像素对应一个显示像素。分析进度由旁边的进度条及左侧分析项目状态显示。

## 预览镜像与旋转（v0.3.1）

预览上方提供「↶ 90°」「↷ 90°」「上下镜像」「左右镜像」「快速对齐模板」「原始方向」。新导入的图像保持原方向，软件不会自动转向；所有旋转严格按 90° 步进。镜像以当前屏幕的上下 / 左右为准，状态文字显示当前角度及镜像。切换队列图像时保留各自本次打开期间的方向，重新打开图像默认恢复原方向。

「快速对齐模板」先使用当前图像已有的模板配准或四点锚定，恢复与模板一致的轴向及必要镜像，并将图像居中适合窗口；没有配准时，后台匹配图像缓存预览与模板缩略图，不进行完整测量。特征不足、匹配方向不明确时保留当前方向并说明原因。该功能只选择 0 / 90 / 180 / 270°，不做任意角度去斜、透视拉正或按模板重裁切。

底图、原像素显示瓦片、热力图和测点一起变换；数字保持正向可读。旋转后仍可滚轮缩放、100% 查看、点击测点及进行四点配准；比较窗口同步方向、缩放和平移。「原始方向」清除全部预览旋转和镜像，居中适合窗口。

预览方向不写入测量参数，不改写源图或报告数据，也不会因为点击方向按钮重新分析。测点位置、RGB dx / dy 和导出报告仍以原扫描图坐标为准；「USAF 竖线 / 横线」仍指原测量方向。预览旋转不能替代测量配准。

## 多项分析一次运行（v0.3.0）

左侧“分析项目”列表替代原来的指标下拉菜单。勾选需要的项目，再点击一次“分析选中图像”或“分析全部”；每张图只提交一个后台测量作业，共用解码、配准和原像素数据。共用分析器可能同时产生关联指标，完整测量仍保留，勾选决定本轮汇总和导出的项目。

开始后，本轮勾选项目显示旋转动画和「分析中 · 共用测量 · …%」。这是同一张图共用测量作业的进度，各项目会一起更新。后续图片显示「已排队」；完成后改为结果状态，失败或取消会停止动画并显示对应原因。运行期间改变勾选不会改变已提交的任务；切换图片或模板仅显示相符任务的状态。

- “全选可用”勾选当前模板支持的单图分析，“清空”取消勾选；灰色项目不能选择，第二行和悬停提示给出原因。
- 点击项目名称切换当前热力图 / 曲线 / 测点明细；勾选本身不会开始分析。改变勾选后再次点击分析，才会生成新的本轮汇总。
- “所选分析结果”页自动汇总每个项目、每个测量通道的有效数量、均值、最大值和单位。没有有效值时显示原因，不能把未测得当成零。
- 勾选 RGB 位移自动补齐 RGB；勾选对齐前后灰度变化自动补齐 RGBY。输入曲线和剪切策略保持用户选择。
- 最佳焦位地图与 RGB 焦位差是序列结果，列表中没有单图复选框；先使用“焦位 / 垫高序列”拟合，再点击这些项目查看。

导出时 `report.html` / `report.pdf` 包含本轮全部所选项目的结果表和通道热力图，同一项目各通道共用色标。`detail-report.html` / `detail-report.pdf` 保留完整 CTF / SFR 曲线和详细测量报告；`analysis-results.json` / `analysis-results.csv` 是所选结果汇总，`analyses/` 保存各项目 / 通道热力图。原始元素测量仍保存在 `result.json` 和 `measurements.csv`，整卡曲线长表继续保留。勾选列表会随偏好和会话保存；打开旧记录仍可查看已有测量并重新分析。

## 参数示例

斜边 ROI 内只留一条直线边缘，推荐 2°–7°。两侧留足稳定平台，避免包含外框。4× 或 8× ESF 过采样、Hamming/Hann LSF 窗、直线/二次边缘拟合可切换。MTF50 无法在 Nyquist 内穿越时留空并提示，不强行外推。

USAF：
    {"group": 2, "element": 4, "direction": "vertical"}
组/元素给出名义频率 2^(group+(element-1)/6) lp/mm；vertical 指竖向条纹，测量方向为横向。ROI 紧框住一个三条线元素，排除标签。结果含 CTF 与按阈值判读的 resolved，不把它直接叫 MTF。

二值星图：
    {"cycles": 72, "pattern": "binary", "center": [0.5, 0.5]}
cycles 是一圈线对数。程序输出相对 CTF 与固定频率对比度；只分析 Nyquist 以内且完整覆盖的圆环。中心可手工修正。

正弦星图：
    {"cycles": 72, "pattern": "sinusoidal", "reference_modulation": 0.8}
有真实参考调制度才叫 MTF；没有参考时为相对响应。印刷调制度不应直接假定为 1。

色块：
    {"rgb_space": "sRGB", "reference_lab": [50, 0, 0]}
必须是已知 sRGB 编码/线性数据、D65 Lab 参考。软件会拒绝直接对 RAW 相机 RGB 输出 ΔE。

灰阶块：
    {"reference_density": 1.0}
每块单独标注；报告输出参考密度和测量均值/噪声，完整 OECF/动态范围认证流程仍需进一步实现。已有标定 OECF 可导入：
    {"encoded": [0, 0.1, 0.5, 1], "linear": [0, 0.01, 0.22, 1]}
两数组等长、至少三点、单调、范围在 [0,1]。

## 调焦/垫高序列

使用同一图卡、曝光、位深、去马赛克、测量设置与分辨率。推荐 7–11 个焦位，每个峰值两侧至少两个采样。文件名可写 scan_z-0.25mm.tif 或 frame_z12um.tif；没有实际高度则输入相对序号，不能从序号推出机械角度。

分析全部图像，再在焦位弹窗确认高度和单位。重复焦位取中位数。平坦、凹性不足、拟合不稳或采样边界峰值不会输出 ROI 最佳焦位。报告的 uncertainty 是局部二次拟合统计估计，不是校准实验室给出的测量不确定度。

多频率序列推荐「整卡多频率调焦评分」与 ALL：分别输出 R/G/B/Y/Y_align 最佳焦位和 R−G、B−G 匹配区域的轴向焦差。热力图指标支持最佳焦位及相对 G 的焦位差。仅有单帧时不会生成这些数值。

默认综合推荐改善较弱区域，也可中心优先或全幅平均。场面平面与径向曲率是一种近似拟合，需空间覆盖和足够秩；图卡不平、夹持、载台、照明与镜头都可能造成差异，不能据单图确认歪轴。

## 比较、报告与会话

左下选择参考图像，出现同步缩放/平移的第二视图；两张使用同一热力图范围，所选 ROI 曲线的虚线是参考。不同模板不会可靠对应，软件会提示。

热力图白点是实测位置。v0.5.1 将彩色覆盖外缘从测点中心扩展到有效测试区域的边界：测点之间线性插值，外侧使用最近网格边界的值延续填色；区域外与明显大空洞透明。边缘颜色是显示估计，不增加实测点，也不改变原始测量值。单个测试区域及单行 / 单列都可显示完整区域；整卡汇总、RGB 位移和焦位图根据保存的单元配准恢复真实范围，不使用旧的 4 px 占位框。

当前指标未测得的测试区域用灰色斜线和灰点表示，悬停可查看原因。灰色不代表零分辨率，也不参与均值或颜色标尺。插值使用完整测试布局判断相邻关系，不会把远隔两端的少量有效测点连成色带，也不会跨过缺失测点填色。CTF50/20/10 必须有可靠的阈值交点；曲线未跨阈值或三条纹已不可分辨时会留空。可点击“查看已确认分辨率热力图”查看整卡的离散分辨率结果。以上显示修复也适用于旧分析记录，无需重新扫描；报告需重新导出。

专业模式的「测试区域之间插值，并延伸至区域边界」默认开启；关闭后仅在各测试区域内填色，区域间留空。预览、比较、PNG 和重新导出的 HTML / PDF 采用相同规则。已有分析记录可直接重新打开，无需重新测量；已导出的报告需重新导出以更新显示。

「—」表示所选指标不适用于该图案；「×」表示该区域测量无效。颜色本身不证明过/不过门限，需查看图例、单位、标志和曲线。

保存会话：结果 JSON + SQLite，可重开、保留算法参数和文件指纹。会话不复制巨大的原图片，移动图片后须恢复路径或重新导入。源文件变化会拒绝把旧数据叠加在新图上。

「导出报告」打开选项窗口，可选 HTML、PDF 或两者，填写报告文件名、显示标题和保存位置，选择是否附完整曲线报告、JSON / CSV 数据及独立热力图 PNG。窗口底部预览最终文件夹路径。点击导出后，所有文件统一放在以报告文件名命名的新文件夹；重名自动使用“名称 (2)”等编号，已有报告不会被覆盖。取消不创建文件。若不需要附件可全部取消，只保存选定格式的主报告。

报告包含本轮所有勾选项目及各有效通道；详细报告保留完整测量曲线。HTML 始终内嵌所需图像，可离线查看；复制单个 HTML 文件即可查看。PDF 供打印和存档。勾选数据附件时也保存焦位序列参数。源图只读，软件不改写 RAW/TIFF。

v0.4.0 的左侧每个项目悬停显示简要原理、用途及限制；灰色项目同时说明缺少哪种图案或前提。新图卡使用说明、整卡与局部拍摄流程见 [混合图卡](MIXED_TARGETS.md)，可公开打印的源文件与许可证在软件根目录 template 文件夹。

监视文件夹仅处理新增且尺寸/时间稳定并关闭的图像，自动分析使用当时的模板和参数。它不控制相机或 V850 的扫描驱动。

MTF Mapper 可安装到本地，在资源设置填写可执行文件路径。该入口启动独立复核并保存命令和日志，不把尚未对齐解码/算法参数的数值冒充同一测量后端。

## 故障检查

- 48-bit TIFF 太慢：检查是否加载 libvips，缓存磁盘和杀毒扫描；info 命令显示版本。
- RAW 预算不足：提高资源预算，或外部转成已知线性 16-bit TIFF。GFX100 冷解码测试约 2.14 GiB 工作集，估算预算更保守。
- Nikon Z8 HE/HE★：本版未支持，选择无损 NEF 或外部转换。
- 结果无效：检查剪切、ROI 角度、图案编号、星图中心、物理标定、曲线与混叠。放宽剪切拒绝只消除门控，不能恢复丢失的信息。
- 中文截图/报告空字：软件在 Windows Qt offscreen 模式加载本机微软雅黑；不随分发包复制 Windows 字体。


焦位弹窗需勾选实测载台/图卡高度，才会输出表观倾角；镜头马达 mm 参数不直接等于物理高度。
桌面界面的监视模式为每个采集文件创建后台快照，连续覆盖同一 capture.tif 也能保留前一帧用于比较。快照有独立缓存预算，达到上限会提示停止导入，不自动删除正在使用的捕获。需要长期保存时请一起保存原图/快照。CLI watch 保存按指纹区分的结果；使用 CLI 时请让采集程序保留不同文件名的原图。
