# 图像质量工作台：参考值与结果评价

规则版本：`2026-10-17.1`。覆盖工作台全部 13 个任务。每个项目保存中文名称、当前值、原生单位、参考、评价条件、依据、评价、解读、下一步和定义来源。实现位于 `src/mutex_imatest/lab_evaluation.py`，与单图 ROI 评价独立。

## 如何查看

选择任务后，任务提示会列出评价前提，结果区显示该任务的参考值与评价标准；“参考值 / 评价标准”按钮可以再次查看。执行后，结果区先显示评价，再显示原始输出。相同评价写入 `lab-result.json` 的 `evaluation` 字段和离线 `report.html`。HTML 可通过浏览器打印为 PDF；打印视图保留完整评价表。

已有的工作台报告若没有评价字段，重新调用 `export_lab_report` 时会按当前规则加入评价展示，原始测量输出保持不变。

## 五种依据必须区分

| 依据 | 用法 |
| --- | --- |
| 数学 / 算法定义 | 例如同一图像 SSIM=1、MSE=0；RMS 理想值为 0。它们是参照，不代表真实设备能或必须达到。 |
| 算法前提 | 例如 PTC 至少 4 个有效曝光级别、CCM 至少 6 色块、多视图标定至少 5 个不同姿态。它们保证本实现能计算，不能当作设备合格线。 |
| 项目工程建议 | PTC R² 低于 0.98 提醒复核。此数值来自本项目的工程处理规则，**不是 EMVA 或 ISO 的通用合格线**。 |
| 相对比较 | 噪声、清晰度、CCM 前后误差等，必须匹配采集条件、尺度、ROI 和处理方式。 |
| 用户目标 | 明确为当前用途设置的原生单位限值。只有足够有效数据才可评价“达到用户目标”。 |

未设用户目标时，设备质量通常显示“待设目标”；这不是缺少评价，而是明确说明现有定义并不提供一个跨设备、跨用途的合格阈值。

## 按任务解释结果

| 任务 | 参考与主要输出 | 评价范围与限制 |
| --- | --- | --- |
| 双图比较 | SSIM 接近 1、MSE 接近 0 表示更接近指定参考；PSNR 越大表示同尺度像素误差越小。 | 必须同尺度、同 ROI、同解码且已对齐。PSNR 不是传感器 SNR，SSIM 不是实际分辨率。MSE=0 时 PSNR 为 +∞；JSON 保留 null，同时保存明确的 `display_value`，不混同于未测得或 0 dB。 |
| PTC | 正斜率系统增益、倒数转换系数、黑电平、暗场时间噪声、DSNU、PRNU、R²、截距、模型、有效曝光级别与剪切。 | 必须为线性、未处理、同温度同增益的单色 / 同 CFA 像素。增益大不等于更好。电子单位依赖有效增益；PRNU 包含照明、镜头和靶材。满阱及动态范围只是用户饱和 DN 的条件估计，不能通过其数值认证满阱。 |
| 暗平场校正 | 有效响应掩码比例与输出文件数量。 | 掩码阈值为本算法定义；写出成功只显示“操作完成”。独立平场残余不均匀未自动测量，显示数据不足；需用新图像验证。 |
| CCM | 拟合色块平均 / 最差 ΔE00、前后相对变化、条件数、色块数、矩阵与偏置。 | 色差理想参照为 0；不套用统一肉眼可见阈值。结果是训练误差，不能代替独立验证。条件数 10⁶ 是算法拒绝界限。未知输入响应不能据色差值判断达到线性 RGB 标定目标。 |
| OECF | 灰阶数量、严格单调性、实测编码上下界与跨度。 | 只在实测范围插值，范围外夹到端点；最亮参考归一化到 1 不代表到达传感器饱和。表可逆不等于完成全量程辐射标定。 |
| 多视图标定 | 总体和最差视图重投影 RMS、有效 / 排除视图、视场、内参与畸变系数。 | RMS 理想为 0 px，应按用途误差预算设限；不提供通用 0.5 / 1 px 合格线。低训练残差不保证独立几何精度，系数大小不能直接用于镜头排名。 |
| 去畸变 | 已生成文件数量、待独立测量的校正后残差。 | 图像已插值重采样；文件生成不证明几何精度或分辨率改善。需保持焦距、对焦、裁切和分辨率与标定一致。 |
| 视频 | 观察时长、亮度变动、平移 RMS 与有效间隔比例、剪切、有效 MTF 帧数、梯度峰值时刻、AE / AWB / AF 稳定与单侧超调。 | `step_declared:true` 才解释 AE / AF 阶跃；`neutral_roi_confirmed:true` 才解释 AWB。未证实稳定不能填 0 秒。相邻平移不是 ISO 防抖档数；帧亮度变动不是频闪频率、SVM 或 PstLM。 |
| 重复帧 | 视频公共统计，加归一化信号时间噪声、空间固定分量和表观 PRNU。 | 场景、曝光、坐标、处理必须固定；运动和照明会混入噪声。`uniform_roi_confirmed:true` 才按均匀平场解读 PRNU；这些数据不能直接变成电子读出噪声。 |
| 仿真 | 高斯模糊、满阱、读出噪声、PRNU、曝光、Gamma、量化设定及模型剪切比例。 | 输入参数显示“仿真设定”，不会标成设备实测合格。模型没有完整衍射 / 像差 / CFA / 去马赛克链；Gamma 是本模型的幂律。 |
| 采集 | 实际帧数、完整性与记录间隔中位数。 | 只有帧数与请求相符才显示任务完整；本机读取 / 写文件时刻不是曝光硬件时间戳。驱动转换 RGB 8-bit 不是传感器 RAW。 |
| 测试计划 | 执行数量、综合状态、每个测试的通道、聚合方式、限值、有效 / 匹配数量、原生数值与评价。 | 不只信任顶层 `pass`。必须存在完整且有效的限值明细；空值、非有限数、缺少有效测点或异常不能通过。计划只覆盖其明确指定的项目。 |
| 锐度排名 | 有效 MTF50 图像数、候选集最高 MTF50 和最高梯度分数。 | 至少两张有效 MTF50 才有 MTF 排名意义。固定 ROI、尺度、曝光与处理；噪声和锐化会影响分数，梯度分数不能换算 DPI。 |

## 保存用户限值

工作台参数可添加 `evaluation_targets`，键为评价表对应的 `metric`，上下限都按该输出的原生单位，包含边界。例如双图比较：

```json
{
  "roi": [0, 0, 512, 512],
  "channel": "Y",
  "evaluation_targets": {
    "ssim": {"min": 0.98},
    "psnr_db": {"min": 40},
    "mse": {"max": 0.0001}
  }
}
```

这些数字只演示格式，**不是推荐通用阈值**。例如校准重投影限值使用 `rms_px`，视频稳定时间使用 `ae.settling_seconds`，重复帧噪声使用 `noise.temporal_noise`。测试计划仍使用原有计划 `limits` 作为正式规则。

规则版本和实际限值随结果保存，便于复现。目标值必须有限，`min≤max`；NaN、Inf、缺失测量和无效输出都不会被判为达到目标。模型参数、真实饱和端未验证的满阱估计、上界 / 下界和缺少前提的诊断保留其条件状态，即使设置了数值目标也不升级成质量通过。

## 评价标签

“达到用户目标 / 未达用户目标”只用于当前明确目标。“参考解读”用于定义或相对信息。“需要复核”用于工程提醒或未观察到稳定。“数据不足 / 数据无效”明确拒绝空值或失效证据。“条件估计”保留未确认饱和端、测量上界 / 下界等限制。“仿真设定 / 操作完成”分别表示模型配置与文件操作，不表示光学或传感器性能认证。

## 一手资料与本实现的区别

以下资料用于测量定义；软件中的用途目标和工程提醒由本项目另外标明，不归属于这些资料的合格要求。检索日期：2026-10-17。

- [Wang 等，SSIM 原作者说明与论文](https://ece.uwaterloo.ca/~z70wang/research/ssim/)：SSIM 是指定参考图像下的结构相似性量，尺度与观看条件会影响解释。本实现直接使用原像素单尺度统计，不采用网页建议的预降采样观看尺度。
- [OpenCV：PSNR / SSIM](https://docs.opencv.org/4.x/d5/dc4/tutorial_video_input_psnr_ssim.html)：PSNR 由给定动态尺度和均方误差定义。软件使用归一化 `data_range=1`。
- [EMVA 1288 Release 4.0 Linear](https://www.emva.org/wp-content/uploads/EMVA1288Linear_4.0Release.pdf)：线性模型把时间噪声方差与平均光生信号联系起来；区分时间噪声、DSNU 和 PRNU。软件是有限 ROI 和帧组的工程实现，未完成规定采集、光子定标、QE、饱和及全部报告程序，不构成 EMVA1288 符合性声明。
- [CIE：CIEDE2000 定义](https://www.cie.co.at/publications/colorimetry-part-6-ciede2000-colour-difference-formula-0)：提供色差公式和适用参考条件；该定义不为本应用场景指定统一验收阈值。
- [Imatest：CCM](https://docs.imatest.com/docs/colormatrix)：颜色矩阵可针对指定参考色块优化。本工作台明确区分拟合误差与独立验证，不照搬商业产品结果作为本程序的验证。
- [Imatest：Color/Tone](https://docs.imatest.com/docs/color-tone/)：灰阶用于输入响应和相关测量。本项目 LUT 有实测区间及端点夹取限制。
- [OpenCV：相机标定与重建](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)：重投影优化和相机模型；软件报告总体和逐视图 RMS，但仍要求独立验证。
- [OpenCV：相位相关](https://docs.opencv.org/4.x/d7/df3/group__imgproc__motion.html)：相位相关估计平移；本项目只保留响应足够的相邻采样间隔。
- [OpenCV：视频 I/O 属性](https://docs.opencv.org/4.x/d4/d15/group__videoio__flags__base.html)：读取属性依赖设备、驱动和后端；本机时间记录不能当作曝光同步证据。
