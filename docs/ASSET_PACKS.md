# 图卡资产与软件开源边界

软件源代码 GPL-3.0-or-later；用户图卡原始 SVG/PDF 不自动获得开源或再分发许可。公开 `template/` 资产各自采用清单中标明的 CC0 或 CC BY-SA 3.0 许可。私有图卡原始文件、用户实拍样本、输出和旧独立打包器不进入公开源码或便携分发；经授权的派生模板资产按下节单独提供。

## 随发布包提供的授权资产 `.mxasset`

完整 Windows、源码与模板 Release 包含「调焦卡_x1」及「西门子星图 + ISO12233 0.5×」的测量几何与 PNG 栅格参考，位于 `template/bundled/`。它们与内置合成卡、6 套公开图卡一起构成全部 9 套可用模板；Git 仓库不包含这两套授权资产。

`.mxasset` 使用公开的应用加载口令，用户可离线直接选择。这种二进制容器不声称对可测量的几何或栅格提供保密，也不是 DRM。原 SVG/PDF 不进入容器；图卡作品仍保留其私有版权，代码 GPL 不授予作品的开源许可。

用户自行导出的 `.mxtpl` 使用用户自己的秘密口令，与内置资产加载口令相互独立。构建与分发边界见 [构建指南](BUILDING.md#随发布包提供全部模板)。

## v0.5.0 加密模板 `.mxtpl`

通过「图卡模板 → 导出当前模板（加密）」导出，再用「导入模板包」加载。导出要求至少 8 位口令和二次确认，导入需要相同口令。口令不保存在偏好或模板包内。

容器采用 ZIP / DEFLATE level 1，只包含 `manifest.json` 和 `encrypted.bin`。明文 manifest 只记录格式版本、算法和解密参数；经 Scrypt（N=32768、r=8、p=1，随机 16 字节盐）派生 AES-256 密钥，使用 AES-GCM 和随机 12 字节 nonce 认证加密。manifest 同时作为认证附加数据。每次导出使用新的随机参数。

加密载荷为测量定义、至多 4096 像素的配准栅格和至多 512 像素的预览图。PNG 从像素重建，不携带源图元数据。不会嵌入原 SVG/PDF、本机源路径或矢量对象。栅格参考支持已有区域和局部图卡的定位；再次展开矢量图需要用户本地重新关联源文件。

读取器在写缓存前完成口令认证、结构、条目、大小、像素数量与测量定义验证；拒绝多余条目、路径穿越、重复条目、篡改和解压炸弹。导出不覆盖已有文件；失败时清理本次创建的不完整文件。读取失败不会把未经认证的文件写入模板库。

这是对模板包保存状态的口令加密，并让原始矢量文件留在原电脑。导入后，软件需要在本机缓存派生栅格供显示与配准；拥有口令的使用者可以访问这些派生数据。分享前仍应确认图卡及其派生物的再分发许可。

## 兼容格式与本地工作文件

用户库使用 JSON 工作定义、本地源路径和 PNG 缩略图；它们留在本机，不属于加密导出包。公开图卡库为可再分发、可编辑资产，随软件保留其 SVG/PDF、署名和许可证。

旧 `.mchart` 继续只读兼容。它是未加密 ZIP / MessagePack 容器，可能含压缩的 SVG/PDF 原字节；二进制包装不提供保密。旧私有 `private_tools/pack_chart.py` 仅供本地兼容使用，不随公开包分发。新界面统一导出 `.mxtpl`，不会生成含原始矢量文件的旧包。
