# 整卡多频率与 RGB（v0.3.0）

1. 导入扫描 / 翻拍图像。在模板编辑器导入 SVG，核对实际尺寸。USAF 按 1:1 制作且物理尺寸已确认时，勾选「实际尺寸已校准」。PDF 可作模板背景并手工标注；自动全频率解析目前支持 SVG 中已展开 transform 的矩形 / 四点多边形条纹。
2. 保存模板，点击主窗口「整卡多频率 / RGB」。程序从矢量条纹尺寸推导 USAF 组 / 元素，展开全频率、双方向，执行原像素逐单元定位。SVG 中覆盖条纹的文字会在模板预检时避开，取样带随镜像方向变换。
3. 此按钮选择 RGBY 五通道，并保留剪切数值和警告用于相对调焦。输入曲线保持原选择。未知曲线下的 CTF 是输入信号响应，不能声称线性光学 MTF。
4. 指标「已确认分辨率」显示每个重复单元的最高连续通过频率；双向视图取较弱方向。可切竖线 / 横线观察方向差异。竖纹测横向细节，横纹测纵向细节。
5. 单频对比度仍可查看；下方频率框选择组 / 元素。这个频率框不改变整卡曲线或已确认分辨率。
6. 通道框可选 G、R、B、Y（RGB 对齐前灰度）或 Y_align（RGB 对齐后灰度）。这选择测量叠加层和数值，底图仍显示原始 RGB 扫描预览。点白色测量点显示该单元五通道完整 CTF；实线竖纹，虚线横纹。低缩放时隐藏数字标签以避免遮挡，悬停仍显示数值。
7. 「整卡 / RGB 汇总」列出各通道最高、中位、P10 分辨率、有效覆盖和 RGB 位移。专业设置可改阈值、相对 / 绝对阈值模式、LW/PH 参考高度和 RGB 搜索范围；改变后需重新分析。

## 模板与可用分析

同一源文件、同页、同物理尺寸且名称相同的生成模板会合并为一个：保留全频率横竖方向、RGB / 灰度分析、额外手工标注区域和标定；升级为全频率时覆盖同一个模板，不再新增同名版本。故意设置不同名称、页码或物理尺寸的模板保持独立。合并前全部原模板及 SHA-256 清单保存在图卡库 `backups/merge-*`；旧结果中的模板快照不改写，通过旧编号别名找到合并后的库模板。

“RGB 位移 R−G（二维幅值）”与“RGB 位移 B−G（二维幅值）”分别固定对应通道，自动切换 R / B；横向与纵向分量可在测量明细中查看，也可选“RGB 相对 G 横向 / 纵向位移”切换 R / B 查看方向。正方向为右 / 下。位移有效性单独检查 RGB 配准，不因 CTF 分辨率判读失败而被连带排除。单斜边模板的 R−G / B−G 为法向有符号投影，名称会明确标注。

可用选项为白底深青色粗体；不可用选项为灰底灰字，附“不可用”，不能点击，悬停显示所需图案或前提。此模板自动提取的 USAF 提供 CTF / 分辨率，未标注有效斜边时 MTF 项保持禁用；焦位与焦位差须完成序列拟合后启用。图案已支持但测量失败时仍可选，以便查看失败标志。混合模板中的额外非 USAF 区域也会分析；USAF 局部配准借用最近单元，并保留提示。

左侧勾选列表支持一次选择多个分析项目，点击一次分析即可生成所有勾选结果。点击项目名称切换热力图，“所选分析结果”页集中查看各通道数值。勾选记录写入分析设置，报告按本轮实际勾选导出；完整曲线另存于 detail-report.html / detail-report.pdf。[多项分析说明](USER_GUIDE.md#多项分析一次运行v030)。

## 数值定义

- 默认以低频前三个可用三条纹元素中的至少两个建立参考，取 CTF 中位数；默认相对阈值为 20%。绝对模式不除低频参考，但仍检查低频取样有效性。
- 必须识别出三条分离暗线，按频率递增取保守单调包络；早先失败后的高频响应回升不视为恢复分辨率。不可见、低对比度、超 Nyquist、无足够原像素、定位失败与模板遮挡均保留标志。
- 最高通过的离散频率与第一个失败频率共同描述已测范围。CTF50/20/10 只在有效三线测量包围对应阈值时插值；条纹无法分离只提供频率边界，不伪造零 CTF 样本。图卡范围内全通过时为下界，不外推。
- lp/mm 是图卡平面线对频率，需要尺寸标定。等效分辨 DPI = 50.8 × lp/mm，与几何采样 PPI = 25.4 × 像素/mm 分开。采样约 3200 PPI 不代表可分辨 3200 DPI。
- LW/PH = 2 × cy/px × 参考图像高度；LP/PH 为其一半。默认高度取当前扫描图像，包含裁切和长条幅面影响；可明确输入完整画面参考高度。不同单位列分别取最大时，可能对应不同测点。
- R/B 相对 G 的横向位移来自低频图案的相位相关 + ECC 平移拟合。右 / 下为正。每个原始 R/G/B 通道仅整数重新定位 ROI，不做插值测量；对齐灰度把 R/B 按亚像素位移双线性重采样后加权。默认权重 0.2126 / 0.7152 / 0.0722，在选择的传递域内计算，未作色度亮度校准。
- 对齐后灰度的响应不保证更高：亚像素插值本身会改变高频响应，软件如实报告变化百分比。输入若只有 8-bit，导出的 16-bit 派生灰度不会增加原始精度。
- 几何采样、RGB 位移、方向分辨率比、剪切比例、配准 RMS 和调焦评分均可作热力图。区域间线性插值，外缘颜色延续至有效测试单元边界；区域外及大空洞透明。白点仍为实测位置，边缘颜色为显示估计。

## RGB 最佳焦位与轴向位移

单张图像只能给当前清晰度和横向 RGB 位移，不能确定光轴方向最佳焦位、轴向色差、机械歪轴或载台高度。不要把图中最清晰位置直接称为最佳焦位。

拍摄 / 扫描至少 5 个包围峰值的焦位（推荐 7–11），每个峰两侧各两个采样，图卡、曝光、解码和所有测量参数保持一致。分析全部图像后点击「焦位 / 垫高序列」，选择「整卡多频率调焦评分」与 ALL。R/G/B/Y/Y_align 独立拟合；输出各通道综合最佳焦位和逐单元峰值、拟合不确定度、R−G 与 B−G 匹配单元焦位差及热力图。ALL 的综合推荐沿用 G，避免把不同通道焦位混为同一测量。

平坦、边界峰、拟合不稳不会强行给出焦位。焦位面仅作平面 / 径向曲率近似；真实机械角度还要求勾选实测图卡 / 载台轴向高度。没有实际高度则保留相对焦位单位。

## 导出

「导出报告」保存自包含 HTML、PDF、原始 JSON、完整长表 CSV、unit_summary.csv、ctf_curves.csv、五张统一色标热力图、RGB 位移图和 summary.txt。多频率报告始终含五通道和两个方向；当前选择另导出 heatmap.png。51 单元报告约 13 页，完整的两万余条元素测量保留在 JSON/CSV，不逐行打印成上千页。

专业设置「导出对齐前 / 后灰度 TIFF」保存原尺寸 Y.tif、Y_align.tif、alignment_valid_mask.tif 和 gray-export.json。分条带处理，不创建整图浮点副本。整幅对齐使用测点凸包内的线性 RGB 位移场和双线性像素取样；凸包外或越界像素为零，必须结合有效掩码使用。原分析逐单元用局部常量位移，整幅灰度是另外的派生输出，不用于替代原始 R/G/B 测量。

所有原图只读；私有 SVG、扫描和报告不随公开源码 / 便携包分发。

定义参考：[Imatest 单位说明](https://www.imatest.com/docs/imatest.html)、[横向 / 轴向色差说明](https://www.imatest.com/imaging/chromatic-aberration/)、[OpenCV 相位相关](https://docs.opencv.org/3.4.7/d7/df3/group__imgproc__motion.html)。算法为本项目独立实现，没有集成商业代码。
