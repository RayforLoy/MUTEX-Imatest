# USAF CTF 提取方法与缺失值

适用于 v0.7.4 起的整卡 USAF 多频率分析；v0.8.0 使用方法版本 `mutex-usaf-multifrequency-2026.10.19-v4`，补充阈值恰好命中的实测频率和缺失原因。单频手工 ROI、星图及斜边各有自己的测量方法。本次修改不改变原始图像。

## 测量条纹内部的起伏

每个 USAF 元素有三条黑线和两个内部白隙。外侧白底不是内部白隙：细条纹变淡时，白底与整块暗条纹之间仍可能有很高的对比度。旧方法对整个剖面取 90/10 百分位，可能把这种外部轮廓当成条纹响应，错过 CTF50 / CTF20 的交点。

新方法从原像素平均剖面寻找三处暗极小值 D0、D1、D2，以及它们之间的两处亮极大值 W0、W1：

```text
W = (W0 + W1) / 2
D = (D0 + 2 × D1 + D2) / 4
CTF = (W − D) / (W + D)
```

共同的中间黑条分别参与两组明暗比较。另存两个白隙各自的对比度，以及区域整体对比度 `roi_contrast`；后者包含外侧白底，仅作诊断。细条纹在 ≥0.06 cy/px 时，对检测到的极值用相邻三个原生采样作局部二次插值，减少像素采样相位损失；不会拟合出缺失的第三条线，也不对源图像做放大、锐化或去卷积。

条纹必须满足三线分离、间距与中心位置检查。两个内部间隙的起伏均须达到配置中的最小对比信号，并超过平均剖面噪声估计的 6 倍。噪声估计来自去除行间亮度偏移后的相邻行差分；它不能涵盖扫描固定条纹等所有相关噪声。模板已有的洁净取样带、镜像 / 90° 方向映射及原精度读取继续生效。

默认参考是排除模板遮挡后最低三个测试频点中至少两个有效 CTF 的中位数；不会跳到任意高频来重建参考。默认相对模式用 CTF / 低频参考；绝对模式使用输入对比度，仍检查低频参考。输入传递曲线未知时，两者都只是输入信号响应。

## 交点必须由有效实测包围

- CTF50 / CTF20 / CTF10 在相邻有效频点的保守单调包络间，按对数频率插值。图卡范围外不外推。
- 剪切点完全排除，不参与包络更新和交点插值。如果后面仍有相邻、未剪切的三线测量包围阈值，可使用那个连续段，并记录 `ctf_segment_after_clipping`。不会跨过剪切点连线补交点。
- 缺线、低信号、条纹几何失配、噪声不足或频率断档会停止后续交点判读。失败后出现的高频回升不能恢复分辨率。
- 「已确认分辨率」与 CTFnn 是不同指标：前者仍要求从低频开始连续通过三线及阈值检查，在剪切等任何无效点处停止。因此，后续有效段的 CTFnn 可以高于保守的已确认分辨率。
- 双向合并沿用已确认分辨率较弱方向的整组结果；需要比较两个方向的 CTFnn 时，应切换竖线 / 横线，并查看两条曲线。

JSON 同时保留 `sequence_valid`（已确认分辨率的连续支持）、`ctf_support`、`ctf_envelope` 和每个阈值的 `crossing_support`（上下两个元素编号及是否位于已排除剪切点之后）。CSV 的 `ctf_support` / `resolution_contiguous_support` 对应这两种支持。CTF 曲线在无效点处断开，缺失值不会画成实测零值；热力图继续显示未测得区域。

修改了算法版本，旧版与新版焦位评分不能混在同一序列中。旧结果 JSON 不会自动重算；升级后须重新点击分析。

## 验证与使用建议

自动测试使用解析的有限三条纹经过已知高斯点扩散函数后的连续信号作为真值，覆盖不同频率、亚像素相位、传感器噪声及完整阈值曲线。反例包括缺线、错误周期、纯噪声、渐变、单暗块、频率断档、剪切交点及低频参考不足。额外验证旋转 / 镜像、RGB 测量和 GUI / 报告曲线的缺失段。

提高提取率不等于提高光学分辨率。仍然缺失时，先查看两个方向的原像素条纹、定位状态、低频参考和剪切。采集时减少过曝与黑位压死，关闭可控的锐化 / 自动对比度；让所需阈值附近有足够细的频率阶梯与原生像素，能从采集端增加有效证据。已经粘连的黑条不应仅靠降低检测门限变成结果。

## 方法参考

[Imatest Log Frequency](https://docs.imatest.com/docs/log_f) 说明了条纹与正弦响应的区别、像素相位影响，以及极值二次插值；[Edmund Optics Testing and Targets](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/testing-and-targets) 介绍 USAF 离散频率及横竖方向的判读。这些资料用于定义与方法核对。有限三条纹内部取样、质量检查和分段交点规则为本项目独立实现，不声称与商业软件数值等价。
