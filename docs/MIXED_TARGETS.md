# 混合图卡、整卡与局部拍摄

v0.4.0 共用同一套桌面 / CLI 引擎分析斜边、二值或正弦星图、已知频率楔形和 USAF。这里的“通用”表示可检测支持的图案，并不保证从任意图卡照片恢复印刷比例或全部图案。

## 选择与导入

软件根目录 `template/` 是可再分发的公开图卡库，启动后自动出现在模板列表。原创星图 + 斜边、斜边网格和 ISO12233 风格兼容图各提供 SVG、PDF、缩略图与精确 ROI；另有从 Wikimedia Commons 获得、按 CC BY-SA 3.0 保留署名的 Siemens 星和 USAF1951。来源、许可和修改记录见 [署名](../template/ATTRIBUTION.md)。通用 ISO12233 风格图是原创工程图，没有标准认证声明。

私有 SVG / PDF 由“编辑 / 导入图卡模板”导入本机图卡库。PDF 导入后后台寻找完整星图和干净斜边；“自动识别星图 / 斜边”可重新生成候选。已有手工区域、楔形与公开精确定义会保留。检测期间暂时禁用区域编辑和保存，名称、尺寸、校准字段仍可修改；切换源文件会取消旧检测，避免迟到结果覆盖新图卡。请检查候选是否落在正确图案上，再保存。

“西门子星图 + ISO12233 0.5× · 整卡 / 局部”已导入本机，包含 48 个 36 周期二值星、6 个斜边和 20 个楔形。星图周期数、斜边位置与楔形频率是这张图专有参数；用户原 PDF、手机照片和此私有定义不随公开包分发。楔形频率来自高分辨率 PDF 参考栅格估计，结果附 `reference_frequency_approximate` 提示。0.5× 是设计信息，不能代替印制后实际尺寸确认。

## 整卡、局部、旋转与镜像

选择有参考图的模板后默认使用“整卡 / 局部自动配准”。特征匹配和投影变换将模板坐标映射到原始图像，支持整卡、裁切、90° 转向及镜像。只测量投影后完整落入照片范围的区域；被裁切的星图不会用可见碎片冒充完整圆环，越界区域保留原因与空值。

配准必须有足够独特特征、覆盖和一致性。只拍到一个重复星图或几根条纹时可能无法确认它在原卡的位置。参考配准失败后，带 `auto_detect` 的通用模板会独立寻找完整星图 / 斜边，生成该照片自己的测量区域，同时取消物理尺度，避免把局部照片当成整张图卡等比缩放。找不到有效图案则明确失败；可手工框 ROI，必要时做四点配准。此方式不能自动推断任意未知 ISO 楔形的频率参数。

方向按钮仅改变预览。默认保持原图，提供上下 / 左右镜像、顺 / 逆时针 90° 和“快速对齐模板”；不做任意角度旋转。点击测点、原像素瓦片和热力图同步变换，测量结果及 RGB 位移仍使用源图坐标。独立检测的通用区域没有原卡绝对方向，不能用其单位矩阵宣称已恢复模板方向。

## 输出与判读

| 图案 | 可用分析 | 质量边界 |
| --- | --- | --- |
| 斜边 | ESF / LSF / SFR、MTF50 / 50P / 20 / 10、奈奎斯特响应、过冲 / 下冲、边缘拟合 RMS、RGB 法向位移 | 需要单条干净斜边；检查角度、剪切、输入曲线与拟合 |
| 二值星图 | 原始及相对 CTF、CTF50 / 20 / 10、阈值分辨率、8 个 45° 扇区曲线、方向分辨率比 | 不直接转称 MTF；检查周期数、星心、完整圆环、投影几何、基频一致性与混叠 |
| 已知几何楔形 | 连续频率 CTF、CTF50 / 20 / 10、阈值分辨率、分离异常比例、基频一致性和暗条数曲线 | 需要正确频率参数；只在从低频起连续通过条纹分离的区间确认分辨率，高频回升仍保留诊断但不重启确认 |
| 多个有效测点 | 各指标的 RGB / 灰度热力图、幅面及方向差异 | 只覆盖本次实际拍到且有效的区域；插值不代表额外实测点 |

星图方向比是 8 个扇区分辨率最大 / 最小值，接近 1 表示方向较一致；任一扇区无有效分辨率时留空。它不能单独确诊像散。单斜边的 RGB 彩边只约束边缘法线分量，不提供可靠二维位移。整卡 USAF 的二维位移和对齐后灰度继续使用已有的 G 参考局部配准，不按各通道最高分辨率位置相互搬移。

星图的阈值穿越同样只采用从低频起连续通过预期基频检查的区间；失配以后的曲线保留供诊断，不据此给出 CTF50 / 20 / 10 或 MTF 阈值。软件通过外圈与内圈周期故意不同的合成反例验证这一门控。

cy/px 和 LW/PH 可在未知物理尺寸时使用；物方 lp/mm、等效分辨 DPI 需要适用的实物尺寸标定，且几何采样 PPI 与实际分辨率分开显示。阈值未穿越、频率覆盖不足、区域越界或质量检查失败都留空，不填零、不外推。达到图卡最高频率只给出受图卡限制的下界。

未知输入传递曲线保留“输入信号响应”提示；手机 JPEG 已包含去马赛克、锐化、降噪等处理，旧版高对比 ISO12233 还容易剪切。结果不能只归因于镜头光学性能。黑白图卡没有实测色块 / 密度参考时，不输出虚构色差或 OECF 标定。单张照片也不能给出物理轴向最佳焦位、RGB 轴向焦差或机械倾角；这些继续使用焦位 / 垫高序列。

## 已有手机照片回归

本机 `zfold7_12233_200mp.jpg` 由产品 CLI 使用本机私有模板分析，原生 16320×12240 像素。443 个配准内点把照片定位到中部 ISO12233 面板：6 个斜边和 19 个楔形、RGBY 共 100 条有效测量；另一个楔形未通过预期条纹检查，48 个星图均未完整进入画面。没有假定这张局部照片覆盖 A4 整卡。CTF20 / 10 未在有效区间跨阈值、0.15 cy/px 超出楔形测频覆盖、星图方向指标无有效星图时均留空。私有验证与报告保存在本机 output 和 validation/private-mixed-regression，不进入公开软件包。

## 研究来源

本版参考 [Imatest ISO12233 说明](https://www.imatest.com/imaging/iso-12233/) 的旧高对比 / 新低对比图卡差异，以及 [星图说明](https://docs.imatest.com/25.2/starchart) 和 [斜边与星图比较](https://www.imatest.com/imaging/slanted-edge-versus-siemens-star/) 的方向响应、输入处理和归一化影响，增加了上述工程分析。没有照搬商业实现或声称数值与其一致。信息容量、标准噪声和色差等还需要额外测量前提，未从这张黑白图卡推断。
