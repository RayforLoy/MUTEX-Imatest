# 测试内容与可解释范围

这些图案可以在同一张照片上比较不同测量原理。斜边的高对比边缘与星图细节对手机锐化/降噪可能给出不同响应；不把差异简单解释为测量错误。此设计动机参照 [Imatest 对斜边与西门子星的比较](https://www.imatest.com/docs/slant_edge_star_comparison/)，不是使用其软件或复制其图卡。

| 图案/数据 | 产品提供的量 | 使用条件与限制 |
| --- | --- | --- |
| 单独斜边 | ESF/LSF/SFR、MTF50/50P/20/10、Nyquist 响应、过冲/欠冲、边缘拟合残差 | ROI 只含一条边，斜角/采样/剪切等质量检查通过；输入传递曲线未知时标记输入信号响应 |
| 二值西门子星 | CTF 曲线、CTF50/20/10、阈值分辨率、8 方向响应和方向分辨率差异 | 周期数是每圈黑白对数。原生像素不足、星心/透视估计失败时不给虚构数值；不把二值 CTF 称为正弦 MTF |
| 精确频率楔形 | 连续频率 CTF、阈值分辨率、频率分离/混叠提示 | 必须已知条纹几何并与本图配准。每条横截线含 `6+30t` 周期，竖条的 `t` 沿 y、横条的 `t` 沿 x |
| USAF 三线条 | 多频率 CTF、连续通过频率上限、正交方向差异、RGB 配准辅助 | 组/元素及实物比例核对后才能用绝对 lp/mm。频率到达图卡最高频率只代表“图卡限制” |
| RGB 边缘 | R-G/B-G 位移及彩边提示 | 单一斜边只约束边缘法线方向；多方向目标才能进一步约束二维位移；不从单张图给出轴向色焦差 |
| 多点目标 | 分辨率/响应热力图、幅面差异、同位置 RGB 对比 | 只在有效测点覆盖范围内解释。局部拍摄不代表完整幅面；没有焦位/垫高序列就没有物理最佳焦平面 |
| 灰阶条 | 相对数字信号观察 | 文件的 RGB 数值不是印刷后反射率或密度真值。未测色/测密度，不能得到标准色差或独立 OECF 标定 |
| 棋盘格 | 9×7 内角点的投影平面残差 RMS/最大值、63 点残差曲线 | 10×8 格棋盘和白边完整可见，去除单应变换后报告原生像素残差。图案旋转5°，设计格边长16mm；默认未校准。单张图不能独立分离镜头畸变、图卡弯曲、打印误差和角点定位误差，不输出真实畸变百分比或相机内参 |

本版公开原创星图采用 36 个周期，便于较小 ROI 和普通印刷；其用途与 72/144 周期正弦标准图不同。[Imatest 的星图说明](https://docs.imatest.com/25.2/starchart) 可作为进一步阅读，讨论了归一化、分区和输入线性化的影响；本软件保留自己的 CTF 定义与质量标记，不声明输出等同 Imatest。

数学定义：二值星的相位为 `cycles × atan2(y-cy, x-cx)`，黑白占空比 1:1；距星心 `r` 处频率为 `cycles/(2πr)`。正方形斜边相对图卡横纵轴旋转 5°，ROI 截取边中段避开角点。楔形的相位是 `2π(6+30t)(u-0.5)`，`u` 为横截线 0..1 坐标；文件定义以两端 `frequency_samples` 精确记录线性频率规律，渲染采用 513 个纵向节点的矢量边界。截断仅发生在 ROI 边界之外。

打印品质、纸张、墨水、扫描/拍摄光照、光学系统和图像处理都会进入测量链。这里没有随图卡附带实测光谱、密度、尺寸或 MTF 证书。原创图上的 50 mm 检查线可验证缩放；外来 USAF 图可核对组 -2 元素 1 的单根黑线宽度是否为 2 mm。无这些确认时保持 `calibrated=false`。
