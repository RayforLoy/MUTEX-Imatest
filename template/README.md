# MUTEX 公开测试卡库

此目录是可随软件二次分发的公开库，与用户上传的私有图卡相互独立。软件自动读取 `manifest.json` 中列出的定义。所有 PNG 只用于预览和定位；测量只读取实际拍摄/扫描文件的原生像素。

| 软件模板 | 内容 | 图卡许可证 |
| --- | --- | --- |
| 通用西门子星图 / 斜边 · 原创 | 3×3 个 36 黑白周期二值星、18 个 5° 斜边 | CC0-1.0 |
| 通用斜边 · 3×3 双方向 · 原创 | 9 个旋转方块的 18 个单边中段 ROI | CC0-1.0 |
| 通用 ISO12233 风格 · 原创兼容图 | 3 个 36 周期星、8 个斜边、4 个精确频率楔形 | CC0-1.0 |
| 通用棋盘格 · 9×7 内角点 · 原创 | 10×8 格、16 mm 设计格边长、5° 旋转图案、63 个内角点 | CC0-1.0 |
| 开放图卡 · Siemens star · Wimmer | Leonhard Wimmer 的 16 周期星，增加白底和打印尺寸 | CC BY-SA 3.0 |
| 开放图卡 · USAF1951 · Setreset | Setreset 的 -2/1 到 1/6 正交三线条，48 个 ROI | CC BY-SA 3.0 |

通用 ISO12233 是原创风格兼容图，**不是 ISO 官方图，不声明 ISO 合规或认证**。它与市售 ISO12233 图的布局不同；不同版本或局部图像由自动检测寻找实际可见的斜边/星图，不能按本图预设位置强套。外部官方 ISO 图和商业图卡没有因可下载就获得再分发许可，本库没有打包这些图。

打印原图在 `originals/`，同时提供 SVG 和矢量 PDF；实际下载的上游原文件在 `upstream/`，未改动。程序定义在 `definitions/`，小缩略图在 `previews/`，许可全文在 `licenses/`。署名、来源、修改说明见 [ATTRIBUTION.md](ATTRIBUTION.md)，测试方法和限制见 [TEST_METHODS.md](TEST_METHODS.md)。

打印应使用 100% 原尺寸并用尺核对原创图上的 50 mm 检查线。不要选择“适合纸张”后仍沿用设计尺度。定义中的尺寸是设计值，**默认 `calibrated=false`**；确认实物尺寸及正确配准后才启用绝对 lp/mm 和等效 DPI。未标定时仍可显示 cy/px、LW/PH、LP/PH。二值星/楔形测 CTF；斜边测 SFR/MTF，两者阈值不混为一个结果。

整卡、局部图像、90°旋转和镜像都走产品的自动定位流程。没有成功对应参考图而采用通用目标检测时，只报告检测到的实际局部位置，并取消预设物理标定。只有一部分图卡进入画面，或图案重复导致位置不唯一时，不能由缺失部分推算整幅相机/扫描仪表现。

棋盘格可测 `projective_residual_rms_px`、最大角点残差和 63 点残差曲线。测量区域包含完整棋盘和四周白边，辅助标记与旁白在区域之外。局部照片必须仍包含完整棋盘；若棋盘本身被裁掉，区域越界或角点检测失败就不输出残差。它不自动恢复任意局部棋盘，也不凭单张照片给出相机内参或真实镜头畸变百分比。残差同时受打印精度、图卡平整度、成像和角点定位影响。

## 可复现构建

在源代码根目录运行：

```powershell
.venv\Scripts\python.exe scripts/fetch_public_templates.py
.venv\Scripts\python.exe scripts/build_public_templates.py
```

下载脚本仅供维护者显式运行；软件启动不会联网。上游字节和许可证文本必须与已审核 `manifest.json` 的 SHA-256 相符；发生变化时先复核，不能静默替换。生成器只读写此目录，不读取 `example/`、用户上传的 PDF/SVG 或实拍照片。SVG 几何由数学公式重建，PDF 由本地 Qt 矢量打印后用 Poppler 渲染核验；PDF 创建时间和系统字体可能随构建环境变化，最终分发文件的 SHA-256 记录在清单。
